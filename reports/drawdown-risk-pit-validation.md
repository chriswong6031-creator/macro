## Honesty passport

- **Labor leg:** `claims` (the LIVE composition; the stale table predates the claims replacement).
- **Gauge legs:** recession_risk, nfci, ebp, hy_oas.
- **Claims PIT true as-of from:** 2009-06-04 — before that date the `release` frame uses the modelled-release lag calendar for claims (`initial_claims` ~5 bd), not a true ALFRED as-of join. Documented, not silent.
- **Overlap:** Forward windows overlap (horizon-day), so raw N over-counts independent observations by ~horizon; treat Wilson CIs as a lower bound on the true interval width. Bands are contiguous score regions, not disjoint events.
- **Sample starvation:** Only ~2-3 recession/deep-drawdown episodes sit inside the PIT era; the extreme/high bands are dominated by 2008/2020/2022, so their hit-rates are episode-driven, not IID. A recession-RISK read, not a crash oracle.
