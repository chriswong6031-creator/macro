## 0. In plain English

We asked: can our engines stop being disconnected Python scripts and become a living, learning, talking system — with a central brain that hears everything and can even adjust the engines, like the Red Queen?

The census answer is startling: **the organism already exists — it's just missing its nervous system.** We already have ~145 files that engines use to pass signals to each other (undocumented, mostly unversioned), six Claude/LLM "brains" running in production every night (each hard-clamped in code so it can only make us *more* cautious, never less), roughly 24 separate systems that remember predictions and grade them later, several fully-automatic learning loops already adjusting weights in production (safely, with do-no-harm gates), and even a mechanism where a signal must *earn* the right to override another by proving its track record. Nobody can see this whole picture at once — not the operator, not the engines, not the brains. That is the actual problem.

So Neural Web is not "build a brain from scratch." It is: **wire the brain we already have — then grow the mind on top.** One registry that documents every signal. One federated memory that grades every claim. One reliability table that says which engine to trust in which market weather. One graph that shows what confirms and contradicts what. One conductor that knows which engines depend on which data. Reflexes that react to events. And one deliberative AI on top — with supreme *governance* power (it can quarantine engines, rank what deserves attention, propose experiments, demote decaying signals) but zero *authorship* power (it can never invent a signal, a trade, or an escalation) — and even its governance authority is **earned by graded track record, exactly like every other signal in the house**. The Red Queen's omniscience and containment authority — with the constitution she lacked, and a probation period besides.

*Glossary for this doc:* **spine/qledger** = our two existing "what did we predict → what happened" memory systems (quantitative parquet / qualitative claims). **Gauntlet** = pre-registered backtest with committed pass/fail rules. **FDR** = the statistical correction that stops you fooling yourself when you test many things. **PIT** = point-in-time (no hindsight). **Tier ladder** = DISPLAY→SHADOW→CONFIRMER→SCORED, the promotion path every signal climbs by evidence. **can_force** = the existing rule where a radar earns override authority via its graded track record.

## 1. The operator's four questions, answered from evidence

**Q1 — "Will our engines ever cross-communicate? It's messy and undocumented."**
They already do, at scale: the census counts **≈145 distinct cross-engine artifacts (~95 unique names)** — 34 basketdata JSONs across 5 regions, 20 PIT archive streams, 10 alert streams fanning into `alert_triage`, 10 strategy verdict files, ~28 data/ snapshots, ~30 site JSONs, ~12 shared parquet families — plus a second, qualitative event bus (`engine/qbus.py` + `engine/qkernel.py`, 1,261 event keys, live since the Qualitative Intelligence program's W2). The website itself is the IPC layer — engines read other engines' *published site JSON*. What's missing is exactly what the operator senses: no registry, no schemas on the most-consumed hubs (`baskets.json` and `flow.json` are bare; version-stamped at best elsewhere; only `site/signals/*` is jsonschema-enforced), no producer/consumer map, and real rot in the seams: two writers racing on `foresight_cascade.json`; `radar_plus` mutating a published artifact post-emit; the Terminal's intel feed starved since the R2 migration (it reads gitignored `site/stockdata` with no R2 leg); and the sector-pulse per-ticker chip wiring shipped in #1170 then **silently regressed 90 minutes later when #1193 deleted the injection block** — undocumented wiring means nobody noticed. **Verdict: the fix is registry + envelope + CI provenance gate — cheap, transformative, and it repairs found rot.**

**Q2 — "Engines are just gears, not live and breathing — can they become alive?"**
Reframe, with conviction: **the gears must stay gears; the *system around them* becomes alive.** Determinism is the moat — the entire epistemic architecture (PIT replay, `engine.run` deliberately recomputing full regime history each run "so the live signal and the backtest can never drift apart", the CI-enforced null registry, Oracle's Time Machine) only works because computation is dead and replayable. What should live: **sensing** (event tiers exist: whitehouse hourly, fastpath 30-min, live-quotes 10-min, a staleness self-heal born from three real incidents), **routing** (today: hand-ordered YAML, lanes that diverge deliberately AND accidentally — an engine change that reshuffles baskets never refreshes sector_central until nightly; a single changed *data input* cannot narrow the render at all), **memory/learning** (bounded loops already live), and **deliberation** (six brains already live). Liveness = conductor + reflexes + cortex, not 482 daemons.

**Q3 — "How important is this, and how does it go beyond Python scripts?"**
It is the **highest-leverage program on the board**, for a structural reason: every active program (Oracle, options alpha, setup species, qualitative intelligence, prebreakout, HK/Canada…) currently hand-builds its own propagation rails, its own ledger, its own wiring wave. That's why we have ~24 outcome-tracking systems in 9 schema families, **two substrates claiming universality** (`engine/spine.py` and `engine/qledger.py`, built by two different masterplans, with altdata adapted into *both*), and two event buses. Neural Web is the program that makes every other program cheaper — and it is also the *only* program whose subject matter is the connections themselves. "Beyond Python scripts" is not a language question — Python runs every institutional quant stack on earth. A script becomes an organ when it has: a contract (schema + registry entry), memory (graded ledger), a self-model (reliability profile), a place in the nervous system (bus + DAG), and a governor (cortex). That is architecture, not syntax.

**Q4 — "If we add a Fable/AI layer, is it supercharged?"**
Yes — and the census shows the hard parts are already proven in production: six clamped LLM brains (master_brain, ai_desk's 4-analyst adversarial panel, narrative_brain dual-model, risk_brain, whitehouse_brain, altdata_brain), a production MCP read-surface over the whole site/+data tree (Mastermind `bot_mcp.py` with deny-roots and leak audit), and an Opus self-correction loop (`risk_radar_review.py`) **already wired into daily.yml and running nightly as a config-gated no-op** (enabled:False + token + ≥30-graded gate) — arming it is a governance decision, not integration work. What the AI layer lacks today is *senses* (145 files, no coherent view), *shared memory* (fragmented ledgers), *a real runtime* (the current "cortex" is a single cached non-agentic completion, by default to a third-party model), and *governance rails*. N0–N4 give it senses and memory; W7b gives it an agentic frontier-model runtime; the constitution gives it bounded, earned authority. Then the AI layer stops being six scattered narrators and becomes a cortex.

**Article 1 — No origination (A7).** No LLM may invent a signal, trade, or escalation. Inherited from six live clamps; never renegotiated.

**Article 2 — The perimeter is drawn by SURFACE, not by code path.** The operator's money path includes everything that *ranks or escalates*: buy strips, board ordering, top-setups, alert_triage priority inputs, push floors, the attention queue. Each grant's false-grant probability at its actual n is printed in the governance ledger entry. When evidence is insufficient or stale, authority **lapses** — it never persists on absence of evidence. (First application: altdata_brain's grandfathered `actionable: True` flag gets a spine track record and either clears an Article-3 gate or loses the flag.)
