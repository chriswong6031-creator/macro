# 2. Why this matters to Prophet

Raw event calendars are not enough. The same headline can mean radically different things:

- a $1B potential contract ceiling with little funded obligation;
- a $100M funded order for a $500M supplier;
- a clinical primary-completion estimate with no result yet;
- earnings that beat consensus but were already guided;
- earnings that look numerically small but transform a strategically important segment;
- an event with no defensible expectation baseline at all.

Prophet eventually needs to distinguish:

```text
event existence
≠ expectedness
≠ surprise
≠ issuer materiality
≠ price incorporation
```

A single Catalyst Score destroys those distinctions and creates false precision.

The long-term moat is the correction-safe history of:

```text
what was known before event
→ what happened
→ expectation revision / surprise
→ issuer-economic context
→ later price/estimate/path response
```

by domain, event family, issuer and time.

**Question:** What happened or is scheduled?

**Question:** What was reasonably knowable/expected immediately before the outcome?

**Owned downstream by Cell B / accepted incorporation owner. Cell C must not compute it.**

# 8. Issuer materiality contract — high-ambiguity CEO work

This is the most important area to harden before coding.

The receiving Sol must research domain accounting/economic methods and freeze a multidimensional representation.

## Candidate dimension A — Economic scale

Every numeric comparison must specify numerator, denominator, period and uncertainty.

Examples:

- funded obligation / trailing revenue;
- funded annualized expected revenue / segment revenue, only if owner-supported assumptions exist;
- earnings/guidance delta / prior company base;
- asset/indication importance under a Bio owner method if lawful.

**Potential award/IDIQ ceiling is not funded revenue.**

## Candidate dimension B — Realization certainty

Distinguish:

```text
funded / obligated
current award
potential / option ceiling
contingent milestone
scheduled event with unknown outcome
```

## Candidate dimension C — Duration/persistence

One-time, multi-year, recurring, transitory, unknown.

## Candidate dimension D — Issuer concentration/dependency

Customer/program/asset/segment dependence when canonical source supports it.

## Candidate dimension E — Strategic optionality

New platform/program/market/indication significance. Must be visibly separate from directly measurable economics.

## Candidate dimension F — Balance-sheet dependency

Only via Capital Structure/FIF owner. No local cash-runway fabrication.

## Candidate dimension G — Estimability/uncertainty

`MEASURED`, `INTERVAL`, `QUALITATIVE_ONLY`, `UNESTIMABLE`, etc.

### Candidate object

```text
IssuerMaterialityAssessment
  event_id
  issuer_epoch
  method_version
  dimensions[]
  assumptions[]
  source_refs[]
  known_at
  corrected_at?
  estimability
  authority
```

### Mandatory A4 law

Materiality must be independent of the target price reaction later used by Cell B. “The stock rose 20%, therefore the event was material” is circular and prohibited.
