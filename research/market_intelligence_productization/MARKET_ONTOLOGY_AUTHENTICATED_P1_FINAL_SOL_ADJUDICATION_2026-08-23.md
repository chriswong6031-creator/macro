## 3. Binding Mastermind product laws added by this return

### A. Aggregate denominator receipt

Every aggregate over holdings, episodes, evidence, companies, or scenarios must expose:

- total population;
- included population;
- excluded population;
- basis of inclusion;
- missing/stale/fallback share;
- timestamps;
- reconciliation state.

A partial aggregate may not render as complete.

### B. Dominant degradation

If a material portion of the denominator is missing, stale, fallback-priced, unsupported, conflicted, or failed, the affected panel inherits a dominant degraded/partial/abstaining state.

### C. Idempotent object update

All durable updates bind to:

- stable object ID;
- expected version;
- operation key;
- update semantics;
- read-after-write confirmation.

An edit may never silently become an add.

### D. Durable execution receipt

Any monitor/study/scenario/valuation/refresh action must preserve:

- last attempted time;
- last successful time;
- execution state;
- error class;
- output version;
- coverage.

A failed run can never leave a calm `clear/current` state.

### E. Write/read-model reconciliation

A durable object is not accepted until:

1. direct read-after-write succeeds;
2. its canonical library/index enumerates it;
3. counts and filters reconcile;
4. version identity matches;
5. archive/delete lifecycle is defined or explicitly unsupported.

### F. Confidence/probability receipt

Any displayed probability/confidence with decision significance requires:

- semantic definition;
- origin/model/user source;
- inputs;
- calibration basis if probabilistic;
- sensitivity/uncertainty;
- version;
- authority state.

Otherwise it is labeled uncalibrated/display-only.

### G. Output-specific prerequisite gates

For composite analytical products, fail closed only at the output class whose prerequisites are missing.

Example:

- expiry payoff can remain valid from complete option legs/premiums;
- live Greeks require current market/model inputs;
- dealer gamma additionally requires OI and sign assumptions;
- flow interpretation requires classification evidence.
