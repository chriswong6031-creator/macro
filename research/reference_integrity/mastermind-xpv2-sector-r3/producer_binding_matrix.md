# XPV2-SC-R3A — Producer Binding Matrix (Deliverable 2)

Frozen spec: `ADJUDICATIONS.md`. Source lanes: A (Overview), C (Map/Moving/Money),
D (Explore/history), E (Confluence). One consolidated table per view, exact
columns: `| view | field | producer | path/key | authority | transform | clock | access | destination | state/null behavior |`.

Authority values used: **Action** (a graded/gated call the reader is meant to
act on), **Context** (informational, explicitly disclaims action authority),
**CONFLICT** (a context surface rendering action vocabulary — per A3, never
softened to plain "Context"), **model analysis** (LLM commentary, display-tier
— per A8, the ONE field this applies to). No field asserting a market/action
fact is labeled "designer copy" anywhere below. GAP rows are carried forward
verbatim from the dossiers, not filled by inference.
