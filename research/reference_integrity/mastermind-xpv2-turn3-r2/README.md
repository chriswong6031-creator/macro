## Surviving blocker themes

1. **Authority:** Sector Central displays action states, scores, performance, universes, and movement claims that do not match the current canonical producers. Context-only heat/bottoming/movement signals are promoted or implied as action authority.
2. **Capability preservation:** real destinations, premium withholding/hydration, failure/freshness/correction states, full Explore/history journeys, and selected-universe Confluence behavior are missing or unproven.
3. **Responsive composition:** sticky hash entry clips the answer; Confluence state labels disappear; Map is a shrunken desktop chart; several panels overflow or truncate, especially at 200% text zoom.
4. **Accessibility and language:** placeholder links remain focusable, ARIA patterns are invalid or incomplete, chart/table equivalents are missing, touch targets are undersized, and ZH is only partial.
5. **Reference boundary:** the standalone topbar and empty LENS shell must not become production law; canonical navigation and established components remain authoritative.
