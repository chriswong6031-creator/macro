## 1. Grammar v2 (engine/oracle/compounds.py — additive, reviewed)
1. **`sequence` rule:** `{"sequence": {"first": <rule>, "then": <rule>, "within_sessions": N}}` — fires on day t iff `then` evaluates true at t AND `first` evaluated true on ≥1 day s ∈ **[t−N, t−1]** (strictly before t; both causal on the node's own rows; `first` may be any v1 rule incl. nested all/any/episode_event; nesting `sequence` inside `sequence` is REJECTED at validation in v1.2). CAUSALITY LAW: the `first` lookback must never include t (else simultaneous-AND masquerades as sequence) — unit-tested with a fixture where first-and-then are true only on the same day (must NOT fire).
2. **`cooldown_sessions`:** optional top-level spec int — after a fire on a node, later fires on that node within N sessions are suppressed (deterministic left-to-right scan). Applies at `get_entry_dates` so screens/gauntlets/ledgers all inherit it.
