## Phase 0 — P0s + polish (immediate)

1. **Back-to-chart bug (P0)**: on the Analyst pane the "Back to chart" button does
   nothing. NOTE: unmerged terminal PR #4 moves this button — check whether the live bug
   is the same handler, merge-or-supersede #4 in the fix.
2. **Console 404 storm**: `data/<SYM>.intel.json` / `.opts.json` / `.fund.json` 404 for
   symbols outside the deep-coverage universe (KRUS, CNI, COKE, MCD, YELP, 9988.HK,
   crypto fund/opts …), AND the same missing file is re-requested repeatedly in one
   session (KRUS.intel dozens of times). Fix BOTH: (a) a coverage index (tiny
   `data/coverage.json` listing which per-symbol files exist, generated by the ingest
   that writes them; client consults it before fetching) and (b) client-side
   negative-cache so a 404 is never refetched in-session. 404s must go to ~zero on a
   watchlist full of uncovered names.
3. **Timeframe order**: the top-bar timeframe list renders mixed-up; sort chronologically
   (1m…m scale ascending: minutes → hours → D → W → M).
4. **Number font**: `.num` (price displays) is ugly. Replace with a proper tabular-nums
   numeric face (candidates: IBM Plex Mono/Sans tabular, Roboto Mono, JetBrains Mono —
   pick what reads closest to TV's crisp numerals; must support tabular alignment and
   look right at 30px+ headline sizes AND 10px table sizes; keep --font-num token).
5. **Brightness pass**: greys are too dark across the board — raise muted/secondary text
   tokens toward white (TV reads near-white). Token-level change (--muted etc.), verify
   contrast on dark panels on every major page, don't wash out the hierarchy.
