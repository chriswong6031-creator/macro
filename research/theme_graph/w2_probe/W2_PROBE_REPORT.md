Two things this table must not be read past:

- **A "degenerate" CI is not a tight one — it is no resampling at all.** When every
  slot's pair series is no longer than the block length (3) there is
  exactly one block placement, so every bootstrap draw reproduces the original series and
  the interval collapses to a point. Those cells are already UNDERPOWERED-BY-DEPTH; the
  point interval carries no information and is printed only so it cannot be mistaken for
  a measured width.

  preregistered H3 statistic has a mechanical floor for `trading_beta.v0`: consecutive
  estimates are partly the same data. The lag-3 companion column (NOT preregistered —
  disclosed here because the preregistered number alone would overstate the case) repeats
  the same rank autocorrelation three months apart, where the two windows are disjoint.
  Read the beta row's stability claim off the companion, not off the adjacent-month median.

## 8. Disclosed deviations from the preregistration

1. **The cross-market pair is computed as two sub-slots**, `cross_market_pair.us` and
   `cross_market_pair.cn`, each measured against its OWN side's basket union. This is the
   prereg §1 rule ("each side's members are measured against their OWN side's basket")
   made executable; a single mixed cross-section would have been a cross-market lead-lag
   read, which is R7. Net-of-overlap member counts land at 26 (US) and 37 (CN) versus the
   prereg's "~65" estimate for the pair — the estimate was approximate, the union is exact.
2. **`narrative_flare` magnitude field.** The prereg names "news counts" from
   `witness_hist.parquet`. That store carries no news-count column: `news_count_z` is a
   Z-SCORE (range -2.00 → 53.0, i.e. negative values, and only 45% dense), and a negative
   magnitude cannot enter a share denominator without producing shares that neither sum to
   1 nor stay non-negative. The probe therefore uses the densest non-negative magnitude
   field, `channels_lit` (1–5, 100% dense — the count of distinct news channels lit for a
   ticker that day), summed over the month. This is a channel-breadth count, not a news
   volume; the construction id keeps the prereg's `attention_share.us.flare.v0` name and
   this note is the formula's disclosure.
3. **Coverage is pooled over the cell's graded months** (Σ values / Σ members) rather than
   read off a single month, because a cell spans many months and the prereg's "the period's
   members" does not name which. Per-month coverage is in every `cells/*__months.csv`, and
   the latest month's coverage is printed in the §3 table so the pooling can be second-
   guessed from the receipts.
4. **`causal_beta_pair` is the per-member specialisation of**
   `engine/cn_global_beta._causal_beta`. The incumbent takes one shared factor `x` for a
   whole DataFrame (`.div(..., axis=0)`); the ex-self basket return is by definition a
   different series for every member, so the same cov/var ratio and the same `.shift(1)`
   causal lag are applied pairwise. The construction is otherwise unchanged, and the CN
   input store is the one that module's production caller reads
   (`scripts/c1_cn_global_beta.py:_panel()` → `data/china_search/closes.parquet`),
   followed rather than re-decided.
5. **Membership inside a month is held at the month's PIT set** while the 63-session
   window looks back through earlier sessions. The prereg's `B_t` is defined at month `m`,
   and the whole backcast is era=reconstruction anyway (§4), so no PIT claim is made about
   the window's interior.

Two statistics are ADDITIONS rather than departures — the preregistered tests are computed
exactly as frozen, and these are printed beside them because the frozen numbers alone
would read stronger than the data supports:

6. **Lag-3 rank autocorrelation companion (§5).** Adjacent-month betas share about two
   thirds of one 63-session window, so the preregistered H3 statistic carries a
   mechanical floor for `trading_beta.v0`. The companion repeats it three months apart,
   where the windows are disjoint. It does not replace the preregistered number and no
   threshold is applied to it.
7. **Modal tie mass (§6, §7).** The fraction of covered members sitting on one identical
   magnitude. Without it a rank statistic computed over a mostly-tied vector reads as a
   measurement; the column is what shows that the LHB cell's MEASURABLE-NOW and the flare
   cell's near-1.0 autocorrelation are ordering far fewer members than their headline
   numbers suggest.
