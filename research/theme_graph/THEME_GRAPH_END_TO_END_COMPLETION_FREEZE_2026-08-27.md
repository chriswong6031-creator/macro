The GMI Theme/Sector/Neural Graph program is **not complete** because docs merge or individual graph files exist. Core end-to-end completion requires all of the following on the real path:

1. **Truth:** current source/local/structural classifications enter through lawful owner/source contracts with exact identities, PIT membership, source clocks, rights and correction lineage.

3. **Measurement:** eligibility is evidence-based; sparse/incoherent/stale themes abstain; measurable local and canonical themes accrue named-leg ThemeState without a fused magic score.
4. **Cohort intelligence:** an existing U.S. or China stock-selection output can be read unchanged and explained through PIT-valid overlapping semantic neighborhoods and current ThemeState.
5. **Relationships:** a researcher can traverse supported relationship/transmission paths with exact owner provenance and see typed abstention when the economic relationship is unknown.
6. **Sensorium:** owner-approved breadth, participation, price/cycle, attention/flow/crowding or other state legs are composed without recomputation or cross-unit laundering; stale/missing legs remain explicit.
7. **Product:** Neural Web / Market OS can render the canonical graph/state/cohort/path explanation with source/evidence drill-down and honest degraded states. No duplicate UI truth source is created.
8. **Learning:** state/cohort episodes accrue through existing grading/consequence infrastructure with placebo/control law where a performance claim is made; no new grader is created.
9. **Production proof:** at least one U.S. and one China real-data golden journey, plus one cross-market/transmission query, run through the actual production publication/reader path and are visible to the intended user or machine consumer. Browser proof is required for user-facing surfaces.
10. **Authority proof:** all theme intelligence remains display/research context unless a separately accepted forward gauntlet promotes a specific use. Green CI alone is never sufficient.
