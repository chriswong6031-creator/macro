# Foundry lens config (W-FOUNDRY draft-generator panel)

Status: CONFIG OF RECORD (Fable, 2026-07-25; §4 output alongside
`research/PSS_WSIG_SHORTLIST_BY_FABLE.md`). This is the lens roster + process
contract for the W-FOUNDRY draft generator (masterplan §3 W-FOUNDRY step 2).
Validated by the §4 run: 7 lenses × opus reviewers returned 33 candidates, all
12y-testable, 5 registry-clear — the lens diversity did real work (the two
best families came from lenses no single prompt would have combined:
microstructure session-decomposition and flows envelope-decay).

## Process contract (composes existing organs; LLM = proposal tier only)

1. Seeds in (from the seed miner): residual-miss names/classes, personality
   cells with no validated tool, W3 disagreement-ledger near-misses.
2. Each lens below runs as an INDEPENDENT opus agent with the standing context
   pack: program state (§1 of the masterplan), timing ruler (charter §7), the
   two-ruler audition kill, measurement-first law, data reality (12y = daily
   OHLCV only; alt stores = forward-accrual), the DON'T-TEST list, copy law
   R-W1T-3. Output schema: {name, mechanism (one falsifiable sentence),
   construction, measurement_axis (bars-derivable, codex-compatible),
   earliness_claim ∈ {pre-trough, at-trough, post-trough-confirm},
   personality_scope (works-on AND fails-on), falsifier, risk_2022,
   data_needs ∈ {ohlcv-12y, forward-accrual-store, unavailable}}.
3. Cross-check agent (opus): every candidate judged against
   research/DO_NOT_REBUILD.md + config/signal_foundry_blocklist.yml —
   verdict ∈ {clear, collides-killed, adjacent-needs-distinction,
   duplicate-of-seed, duplicate-in-panel}; judge the CONSTRUCTION, not the
   topic word (three different "washout" kills precedent).
4. Drafts to `research/foundry/DRAFT_*.md` (structured prereg drafts);
   rejected candidates append one line + reason to the foundry ledger
   (brainstorm memory). Chokepoint: metabolism/cortex intake ≤3/week (QS-U2);
   Fable/operator adjudication only — NO auto-execution (CHF-R2 deferral,
   clock 2026-10-15).

## Quality levers (from the §4 run)

- Force each lens to name where its mechanism FAILS (personality_scope) — the
  fails-on half is what makes candidates codex-compatible.
- "Deepen a seed only with a materially sharper construction, and credit it" —
  convergent independent deepenings (3 lenses re-derived the same
  undercut-reclaim sharpening in §4) are evidence, record them.
- Every early (pre-trough) candidate must state its 2022-class containment or
  explicitly import the terminality gate (C32) as its conditioner.
- Ground-truth lens gets file-read access and must report only what it
  observes in bars it actually inspected.
