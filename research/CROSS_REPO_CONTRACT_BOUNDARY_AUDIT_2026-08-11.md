# Cross-Repository Contract Boundary Audit — 2026-08-11

## Scope and truth set

This audit covers the three-repository Mastermind system at the fetched remote-default
heads below. Repository labels used throughout are `[macro]`, `[terminal]`, and
`[portfolio]`. Within a citation group, an unlabelled path inherits the immediately
preceding repository label.

| Repository | Audited head | Role at this head |
|---|---|---|
| `[macro] mastermindx-market-intelligence/macro` | `origin/main` at `b49eae4ef69b97581208cd872004f111786381cd` | Market/macro intelligence producer, public artifact publisher, subscriber billing and entitlement authority, Brain gateway, and shared provider-control plane. |
| `[terminal] mastermindx-market-intelligence/mastermind-terminal` | `origin/master` at `eb5216452d17822b76c6d1177e3761f8477dfa95` | Responsive market workstation, same-origin BFF, chart-control executor, Terminal-owned ingest/record signal plane, and user workspace. |
| `[portfolio] mastermindx-market-intelligence/Mastermind` | `origin/master` at `26b31066f4a850445b1bd25c4ee45d4f59938537` | Paper-only seven-book portfolio organism, deterministic managed-book allocation/risk authority, and deterministic constraint/fill authority for user-sized self-directed paper orders. |

Only code and artifacts reachable from those heads are canonical here. Live PR state is
maintained in the Project Active Build Map and is not frozen in this durable audit. Runtime
secret values and uncommitted machine state were not inspected.

The allowed dispositions are exactly: **SAFE**, **HARDEN**, **CONSOLIDATE**, **REMOVE**,
**FOLLOW-UP**, and **UNRESOLVED**. `SAFE` means preserve the boundary, not that the entire
program is finished.

## Findings

| ID | Disposition | Current-head finding and required boundary action |
|---|---|---|
| F-01 | **SAFE** | **Macro remains the sole subscriber-entitlement authority; Terminal is a fail-closed proxy.** Macro writes Stripe-backed `user_entitlements` and invalidates its tier cache (`[macro] app/billing.py`; `[macro] engine/neuralweb/brain_gateway.py::_resolve_tier`). Terminal verifies its Supabase session, never treats `profiles.is_pro` as authority, does not cache negative/error decisions, and sends writes back to Macro (`[terminal] terminal/lib/entitlement.ts`; `[terminal] terminal/app/api/billing/gateway.ts`; `[terminal] terminal/AGENTS.md`). Preserve this direction. |
| F-02 | **SAFE** | **Brain reasoning and chart execution are separated.** Macro owns the widget, quotas, runs, and command origin (`[macro] templates/mm_brain.js`; `[macro] engine/neuralweb/brain_gateway.py`). Terminal exposes a method/path allowlist, mints upstream identity only after session verification, and validates/executes typed chart commands with bounded in-memory AI drawings (`[terminal] terminal/app/api/brain/[...path]/route.ts`; `[terminal] terminal/lib/chartBus.ts`; `[terminal] terminal/components/BrainWidget.tsx`). |
| F-03 | **SAFE** | **The Macro embed is presentation/control, not an authority bridge.** Exact Macro origins are CSP-allowlisted and the lifecycle vocabulary is limited to ready/visual-ready/route/set-symbol/close (`[terminal] terminal/next.config.ts`; `[terminal] terminal/components/EmbeddedTerminalBridge.tsx`; `[terminal] terminal/app/embed/chart/`). It does not transfer signal, entitlement, or portfolio authority. |
| F-04 | **SAFE** | **Terminal now owns the deployed Terminal data wrapper.** Macro's installer copies `[terminal] ops/terminal-data` verbatim and explicitly refuses to maintain a second wrapper body (`[macro] app/deploy/terminal-data-setup.sh`; `[terminal] ops/terminal-data`; `[terminal] DEPLOY.md`). Preserve the one-writer installer law. |
| F-05 | **SAFE** | **Opportunity receipt merge semantics preserve producer meaning.** Terminal validates the whole `opportunity_timeline.v1` artifact, keeps event payloads opaque, distinguishes omitted symbols from explicit empty arrays, and writes receipts beside rather than into the signal verdict (`[terminal] ingest/pull_macro_opportunities.py`; `[macro] scripts/build_opportunity_timeline.py`; `[macro] tests/test_opportunity_timeline.py`). Publication liveness is a separate defect in F-14. |
| F-06 | **HARDEN** | **The Portfolio→Macro projection is narrower than the source ledgers, but it is neither dollar-free nor prose-free.** Position and pending-order rows are key-projected, yet selected book blocks and `performance` are copied as constructed; the committed snapshot includes aggregate simulated `starting_nav`, `current_nav`, `cash`, `invested`, dollar-valued series/notes, paper weights, and reasoning/entry-level prose (`[portfolio] bridge/macro_snapshot.py`; `portfolio/paper_account.py`). Feedback v3 includes bounded nudge detail plus operator-directive prose and opaque IDs; the prose is not ticker-scrubbed and receives only pattern-based secret redaction (`[portfolio] bridge/nw_feedback.py`). Macro re-whitelists only its derived feedback summary; `[macro] scripts/check_private_boundary.py` explicitly exempts the snapshot from dollar and secret-env scans and applies only host-path plus partial forbidden-key checks. Define and test recursive field/value contracts for every public block. In particular, `data/mastermind/key_events.jsonl` currently copies qualifying source-ledger rows without a publication-field projection and needs one. Describe all `data/mastermind/*` operational exports as public-repository-visible rather than private. |
| F-07 | **SAFE** | **Shared provider use does not copy credential values into Portfolio.** Portfolio imports Macro's capability discovery/cooling modules and mirrors only key IDs, outcome, and estimated usage (`[portfolio] brain/provider_waterfall.py`; `[portfolio] brain/key_rotor.py`). Macro's Codex adapter never opens/logs the attached credential and runs in a reduced sandbox (`[macro] engine/codex_provider.py`; `[macro] engine/llm_auth.py`). Version coupling is separately dispositioned in F-10. |
| F-08 | **SAFE** | **There is no direct current Terminal↔Portfolio contract.** Terminal's personalized `portfolio_brief.v1` goes to the Macro gateway (`[terminal] terminal/app/api/portfolio-brief/route.ts`; `[terminal] terminal/lib/portfolioBrief.ts`), while Portfolio's outbound writers target Macro's `site/mastermind/` (`[portfolio] bridge/macro_snapshot.py`; `[portfolio] scripts/export_macro_snapshot.py`). Do not infer that Terminal's Conviction Book is the autonomous Portfolio engine. |
| F-09 | **HARDEN** | **Producer authority and Portfolio defaults conflict.** Macro publishes Neural Web context as context-only with every authority boolean false (`[macro] engine/neuralweb/mastermind_context.py`). Portfolio code nevertheless defaults text prompts ON and typed decision mode to `shrink`, enabling additive candidacy and subtract-only entry shrink, while `[portfolio] config/authority_map.yml` says both defaults are OFF (`[portfolio] brain/neural_web_context.py`). The current committed context has zero FDR-cleared candidates, so present per-name typed effects are inert; that data accident is not an authority guarantee. Fail closed until producer contract, consumer defaults, governance map, tests, and deployed runtime attestation agree. |
| F-10 | **HARDEN** | **Portfolio's Macro invocation is floating and has no committed gitlink pin.** `[portfolio] vendor/macro` is a mode-120000 symlink to `macro_src`; `.gitmodules` contains stale, non-operative pinned-submodule wording. `[portfolio] data_layer/macro_refresh.py` manages a sparse checkout that fetches and resets to current Macro `origin/main`, and Portfolio imports those modules as live Python code. Record and expose the resolved Macro SHA per run, enforce compatibility, and prefer versioned artifacts over floating code. |
| F-11 | **HARDEN** | **The advertised twice-daily Portfolio snapshot publication is not live and the consumer can render stale state as current.** At the audited Macro head, `[macro] site/mastermind/mastermind_snapshot.json` says `generated_at=2026-07-29T22:25:01Z`. Portfolio registers a scheduled exporter and direct push (`[portfolio] app/scheduler.py`; `[portfolio] scripts/export_macro_snapshot.py`), while Macro documents twice-daily out-of-band production (`[macro] scripts/build_mastermind.py`; `[macro] .github/workflows/daily.yml`). Export failures are non-fatal and `[macro] templates/mastermind.js` checks neither schema nor age. Add a producer receipt/SLO and make the page visibly stale or unavailable past budget. |
| F-12 | **HARDEN** | **Reverse-feedback publication has the same producer-green/consumer-green failure mode.** `[macro] site/mastermind/nw_feedback.json` is also stamped `2026-07-29T22:25:01Z`; `[portfolio] bridge/macro_snapshot.py` and `scripts/export_macro_snapshot.py` treat its build/stage/push as best-effort. Macro correctly classifies it stale after four days (`[macro] engine/neuralweb/mastermind_feedback.py`), but the daily summary builder is also non-fatal (`[macro] .github/workflows/daily.yml`; `[macro] scripts/build_mastermind_feedback_summary.py`). Add an independently failing publication heartbeat; do not equate a fresh Macro summary build with a fresh Portfolio producer. |
| F-13 | **HARDEN** | **Several Macro→Terminal refreshes can stay operationally green on last-good data.** Intel explicitly continues after an R2 sync failure (`[terminal] ingest/pull_macro_intel.py`); risk and washout leave existing files when sources are unreachable (`[terminal] ingest/pull_macro_risk.py`; `pull_macro_washout.py`; `pull_macro_washout_history.py`). `[terminal] ops/terminal-data` preserves runtime data across deploys. Keep last-good serving, but require a single manifest to report source, source SHA/object version, payload `as_of`, refresh attempt, and stale/error state so publication loss cannot masquerade as healthy data. |
| F-14 | **HARDEN** | **Opportunity publication can be green at both ends while stopped.** Macro runs the producer with `|| echo ... kept its last complete artifact` (`[macro] .github/workflows/daily.yml`; `[macro] scripts/build_opportunity_timeline.py`). Terminal has no network fallback and deliberately preserves last-good data for omitted symbols (`[terminal] ingest/pull_macro_opportunities.py`; `[terminal] ops/terminal-data`). Preserve atomic/last-good semantics, but fail a dedicated freshness gate when the producer attempt or consumer import receipt misses its cadence. |
| F-15 | **HARDEN** | **Washout is described as display context at the transport seam but is an active entry-admission input in Terminal.** The puller presents `basket_washout_state.v1` as display-only (`[terminal] ingest/pull_macro_washout.py`), while `[terminal] signal_layer/washout_override.py` and `signal_layer/__init__.py` place the same state in the fenced `gc_v2_wo2` live entry rule. Macro owns the PIT state (`[macro] scripts/build_basket_washout_state.py`); Terminal owns the admission rule. Stamp those two authorities explicitly in the shared contract and remove the false display-only claim. |
| F-16 | **HARDEN** | **Portfolio has a separate operator bearer plane, and the authoritative public configuration leaves personal-portfolio CRUD fail-open.** `[portfolio] app/auth.py` authorizes operator paths when `MASTERMIND_AUTH_TOKEN` is absent and blocks `/api/pfolio/*` only in serve-only mode. The authoritative VPS drop-in explicitly sets `MASTERMIND_SERVE_ONLY=0`; `[portfolio] app/main.py` always installs the pfolio router, whose positions GET/POST/PATCH/DELETE and alerts GET routes use `SUPABASE_SERVICE_ROLE_KEY` (`[portfolio] app/pfolio.py`). If those Supabase credentials are present, anonymous callers can read or mutate operator data. Require startup refusal without a bearer on any public authoritative instance and either authenticate or explicitly disable every pfolio route. Keep this plane outside Macro/Terminal subscriber entitlements. |
| F-17 | **CONSOLIDATE** | **Portfolio's external-artifact registry is a dated copy of Macro's producer registry.** `[portfolio] config/contracts.yml` is marked generated `2026-07-06`, mixes synapse-derived rows with census rows, and is never runtime-read across repos; `[macro] config/synapse.yml` continues to evolve. Generate a signed/versioned consumer manifest from Macro's current registry plus explicit Portfolio overrides, and parity-test owner, schema, tier, freshness, effect, and real reader modules. |
| F-18 | **CONSOLIDATE** | **Terminal owns multiple hand-maintained transforms for producer-owned schemas.** US and CN/HK paths independently emit `intel/v1`; risk accepts both `risk_state.v1` and `market_state.v1`; washout/history each define local bridge shapes (`[terminal] ingest/pull_macro_intel.py`, `pull_cn_hk_intel.py`, `pull_macro_risk.py`, `pull_macro_washout.py`, `pull_macro_washout_history.py`). Put producer schemas and conformance fixtures in one versioned contract package; retain Terminal normalization only for presentation fields. |
| F-19 | **CONSOLIDATE** | **Tier/status semantics are normalized independently in two languages.** Macro owns plan vocabulary and legacy normalization (`[macro] config/plans.yml`; `[macro] lib/tiers.py`; `[macro] engine/neuralweb/brain_gateway.py`), while Terminal carries its own tier union/normalizer and gate predicates (`[terminal] terminal/lib/subscriptionTier.ts`; `[terminal] terminal/lib/entitlement.ts`). Generate shared fixtures from Macro's contract so `free/essential/pro/unlimited`, legacy aliases, and active/trialing states cannot drift. |
| F-20 | **CONSOLIDATE** | **Three different things are currently named “portfolio.”** Terminal owns a Supabase user Conviction Book (`[terminal] terminal/app/(shell)/portfolio/`); Macro composes a user-specific descriptive `portfolio_brief.v1` from Supabase positions/watchlists (`[macro] app/main.py`; `[macro] engine/portfolio_brief.py`); Portfolio owns autonomous paper books (`[portfolio] portfolio/`; `[portfolio] bridge/macro_snapshot.py`). Give each a durable semantic ID and never use `portfolio_brief.v1` as evidence of a Terminal↔Portfolio engine bridge. |
| F-21 | **CONSOLIDATE** | **Portfolio is a second direct committer to Macro `main` for reverse artifacts.** `[portfolio] scripts/export_macro_snapshot.py` writes through `vendor/macro`, commits, rebases, and pushes `[macro] site/mastermind/mastermind_snapshot.json`, `site/mastermind/nw_feedback.json`, and `data/mastermind/{cost_summary.json,key_events.jsonl,key_pool_status.json}`; Macro's own workflows may subsequently rewrite/commit `site/`. “Not under `site/`” means not HTTP-served, not private in a public Git repository. `key_events.jsonl` lacks a publication-field projection and can copy qualifying source-ledger fields wholesale, so it needs an explicit whitelist and value scan. Publish one machine-readable route/schema/freshness manifest; keep private review writes API-only and public R2 evidence read-only. |

## Immediate boundary order

1. Stop authority drift first: reconcile F-09 and F-15 before changing any producer payload.
2. Restore observable publication truth: F-11, F-12, and F-14 need receipts/SLOs without
   sacrificing last-good serving.

4. Then consolidate schemas and vocabulary; do not couple Terminal directly to Portfolio to
   “solve” naming or transport duplication.
