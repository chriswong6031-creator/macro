## Template-compile smoke

**Method:** `jinja2.Environment().parse(src)` on the full `china.html.j2` — the same verification
used to confirm the sibling test produces honest output.

**Quote fix:** The Edit tool introduced Unicode left/right curly-quote characters (U+201C, U+201D)
as Jinja2 string delimiters in the `help()` call on L1201. These are not valid Jinja2 string
delimiters (Jinja2 requires ASCII U+0022). Fixed via a targeted Python replacement that converted
the four curly-quote delimiter characters to straight ASCII `"`, leaving the string content
unchanged. All subsequent `env.parse()` runs clean.
