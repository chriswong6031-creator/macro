# GROK-CN-D — China project / EIA / capacity source map

**Verdict:** start the first physical-expansion pilot on **lithium-ion battery manufacturing (cells + modules/packs)**. The working ID is the 24-digit **项目代码**. It is printed on municipal and provincial EIA cover forms and on local NDRC/DRC filing or approval pages. It is not recoverable from an anonymous national search.

Verified live on **2026-08-19** from this session (browser UA `curl`, official `.gov.cn` HTML and EIA PDFs opened this session). National tzxm, MEE EIA pages, MIIT, NDRC, and `ggzy.gov.cn` returned 200. Several provincial tzxm hosts and `creditchina.gov.cn` did not. Every numbered project in §4 was opened as an official page or PDF this session — news write-ups were used only as pointers, never as evidence.

This is a source map, not a collector and not a capacity total. Display-tier only. Do not promote any of these filings to Prophet / sizing / “validated capacity.”

## 0. Industry pick

**Pilot industry: lithium-ion battery manufacturing (C3841), including cell plants, module/pack lines, and the on-campus lab / box / grid hookups that share the same owner family.**

Why this, not the runners-up:

| Candidate | Why it loses the first pilot |
|---|---|
| Lithium-ion cells / modules / packs | **Winner.** Capacity is one number (`GWh/year`) on the EIA cover form. Listed-issuer subsidiaries are nameable (时代新能源, 弗迪, 蜂巢, 海辰, 广汽). 2022–2026 overcapacity produced visible amendments (海辰铜梁 re-EIA) and unstarted filings (`是否开工建设 = 否` on most 2025–26 covers). |
| PV / polysilicon / wafer / cell / module | Same EIA quality, messier units (万吨 vs GW) and more midstream SOE shells. Second pilot, not first. |
| Thermal / renewable generation | Cleaner national energy-bureau lists, worse listed-company mapping. Better as a later energy-system lane. |
| Lithium mining | High signal, tiny N. CATL 枧下窝 is a mine-permit story, not a plant-expansion story. |
| Data-center / 算力 | Newer, capacity units not standardized on EIA covers. |

The first pilot should refuse to add a hookup’s GWh, a lab’s GWh, or a solar line on a Fudi campus into “cell capacity.” Those filings are in the 20-example set on purpose.

## 1. Answers to the observability questions

| Question | Answer | Evidence this session |
|---|---|---|
| Is a project code available? | **Yes, and it is the join key.** Official name: 项目代码. “一项一码”; generated by 全国投资项目在线审批监管平台; “项目整个建设周期的唯一身份标识.” | National FAQ at `https://new.tzxm.gov.cn/bsdt/cjwt/gyxmdm/` (200). NDRC 18-department order, 2017, revised 2023-03-23, Arts. 10–13 (`zfxxgk.ndrc.gov.cn` item 18570, 200). |
| Code format? | Current codes on 2022–26 EIA covers are **24 digits in five dash-separated groups**: `YYMM-RRRRRR-TT-CC-SSSSSS`. `YYMM` = year-month of coding; `RRRRRR` = GB/T 2260 region; `TT` = type (04 = typical enterprise 备案/核准; 07 and 89 appear on some municipal filings); `CC` = channel; `SSSSSS` = serial. Older `YYYY-region-…` codes still exist in 2020–21 Hubei energy-saving reviews; this session could not open those Hubei pages (412). | 18 of 20 examples below carry a live `YYMM-…` code copied from an official cover or approval. |
| Which lifecycle milestones are observable? | **Filing / 备案 or 核准 → EIA first public notice / acceptance / approval → land and construction permits → 排污许可 → 竣工环保验收 → (cells) MIIT 锂离子电池行业规范公告.** Grid hookups and labs get **separate codes**. A major EIA change forces a **re-approval** (海辰铜梁). NDRC Art. 12: delay or adjustment keeps the code; “重大变化，需要重新审批、核准、备案的，应当重新赋码.” | NDRC method Arts. 12–14; 海辰铜梁 2024-09-23 re-EIA HTML; 淮北天科泰 2025-03-12 approval citing 三同时 + 排污许可; company 竣工验收 reports exist (亿纬惠州) but were not fully extracted this session. |
| Exact dates? | **Yes on the government page, not always on the cover form.** EIA公示/批复 pages carry 成文日期 / 公示期. DRC 核准 pages carry 生成日期 and a 文号. Cover forms often leave 备案文号 blank and reuse the project code. Construction start is a checkbox (`是否开工建设`) plus later 建设信息报送, which is login-gated. | 蜂巢南京 核准 2022-10-24; 海辰铜梁 公示 2024-09-23–27; 罗源时代变电站 核准 2026-07-21; most 2025–26 covers = 否 for 开工. |

| Amendment / cancellation? | **Amendment: yes. Cancellation: weakly.** 重大变动 → 重新报批, same or new code per Art. 12. 海辰铜梁 is a live re-approval after a market-driven scope change (2022 approval 渝(铜)环准〔2022〕64号 → 2024 re-EIA, same code `2208-500151-04-01-275517`). ## 3. What a first collector should store

One row per **项目代码**, not per plant name.

```
project_code          # 24-digit, primary key
project_name
legal_owner           # 建设单位, never the listed parent
listed_parent_guess   # inferred, nullable, confidence
role                  # cell | module_pack | lab | box | grid_hookup | campus_other
capacity_gwh          # nullable; never fill from a hookup
capacity_raw          # "年产 15GWh" / "5088万只"
capex_wan_rmb
region_code           # digits 3–8 of the project code
lifecycle             # filed | eia_public | eia_approved | started | permitted | accepted | amended | unstarted
source_url
source_kind           # eia_pdf | eia_html | drc_html
as_of
```

Join rule: same 建设单位 + same park + overlapping 用地 is a **site**, not a capacity sum. Sum only rows with `role=cell` (or `module_pack` if the EIA is module-only and no cell row exists).

## 5. Entity-resolution difficulty (the actual pilot risk)

1. **One site, many codes.** 罗源时代 the cell plant is still only visible through two 2026 *grid* codes, owned by two different legal persons. Adding those codes’ 万元 into “CATL capex” is right; adding a GWh is wrong because neither filing has one.
2. **Name tokens lie.** `时代新能源` ≈ CATL. `颐力时代` ≠ CATL. `长亿时代新能源` ≠ cell capacity. `弗迪` ≈ BYD, but 无为比亚迪实业 on 弗迪 land is solar.
3. **Parent is not on the form.** Resolve 建设单位 → 营业执照 → 股东 → listed ticker as a separate step, with a confidence flag. Do not regex `时代` → `300750`.
4. **Phase splitting.** 盐城弗迪 phase 1 is 15 GWh “二期另行环评”. 广汽 cover says 30 GWh and also mentions 12 GWh. Store the sentence, not a guessed sum.
5. **Amendment vs new code.** 海辰 kept `2208-500151-04-01-275517` across a 重大变动 re-EIA. NDRC Art. 12 says a change that requires 重新备案 gets a *new* code. Both happen. The collector must be able to hold two codes for one site and one code for two EIA generations.
6. **告知承诺制.** 淮北天科泰’s 批复 disclaims substance review. Capacity on that class of page is the applicant’s number.
