# Mastermind Agent OS V1 — implementation plan

Status: **PLAN (proposed)**. Companion to `MASTERMIND_AGENT_OS_ARCHITECTURE.md`.
Phase 0 is **implemented** in this PR; Phases 1–4 are specified for follow-on sessions.

---

## §0 Acceptance gates (spawn-handoff law — these are the deliverable, not the pointer)

Per Macro CLAUDE.md §Spawn-handoff law, acceptance gates live at §0 of the masterplan and must
be repeated **inline** in any spawn prompt. A phase is **not done unless**:

1. `python3 scripts/agentos.py validate` exits 0 on the full record set.
2. Every new validation rule has a test that **fails on the pre-change code** — a green suite
   that was green before the change proves nothing.
3. No phase adds a gate, lease with teeth, dispatcher, or scheduler (architecture invariant I1).
   A reviewer must be able to state why the phase cannot block execution.
4. Every generated artifact carries a DO-NOT-EDIT banner and is regenerated by the same command
   CI runs (I3).
5. Fail-open on join, fail-closed on schema (I4), with a test for each direction.
6. The phase ships through the normal ship loop: commit → push → PR → `merge-on-green` → merged.

## §1 Phase dependency graph

```
Phase 0  (scaffolding + seed)          ← THIS PR, blocking
    │
    ├──► Phase 1  (adoption: DEC/DSC/handoffs written by live sessions)
    ├──► Phase 2  (status generator + CEO brief)
    └──► Phase 3  (context compiler extension)
                        │
                        └──► Phase 4  (hook auto-capture)
```

**Phase 0 is the only blocking dependency.** Phases 1, 2, 3 are independent and parallelizable
across sessions. Phase 4 needs Phase 2's generator and Phase 1's adoption evidence.

## Phase 0 — Scaffolding and seed  *(implemented in this PR)*

**Objective.** Make the join key exist. After this phase a workstream has an ID, a schema, and a
validator, and six real workstreams are represented.

**Dependencies.** None.

**Files.**
- `agentos/README.md` — the contract a cold session reads first
- `agentos/schema/{workstream,decision,discovery,handoff}.schema.yml`
- `agentos/workstreams/WS-*.md` — 6 seeded from live work
- `agentos/decisions/DEC-*.md` — the architecture decisions taken in this session
- `agentos/discoveries/DSC-*.md` — findings from this session's reconnaissance
- `scripts/agentos.py` — `validate` (Phase 0); `status`/`brief`/`compile-context` stubbed
- `tests/test_agentos_schema.py`

**Agent class.** Opus `builder` (shipping code). Schema design is judgment work — main loop.

**Validation.**
- `python3 scripts/agentos.py validate` → exit 0, prints record counts.
- Mutation proof for each hard-fail rule: corrupt a record, confirm exit 1 and the *specific*
  rule fires, restore. A validator that never fails is a validator that never ran.
- `pytest tests/test_agentos_schema.py`.

**What becomes possible.** Every later phase. `WS:<KEY>` becomes citable from PR bodies,
masterplans, and memory. Context compilation becomes a graph walk rather than a search.

## Phase 1 — Adoption

**Objective.** Records get written by real sessions doing real work, not backfilled by a
scaffolding session. Closes **G1** (WHY) and **G2** (cross-account discoveries). **Unblocked 2026-08-12:** `DNR:KILL-PARALLEL-KNOWLEDGE-BASE` was overruled by the Chairman, so this phase may require sessions to write `DSC-*` (see `DEC:AGENTOS-CXI-R12-OVERRULED`).

**Dependencies.** Phase 0.

**Work.**
1. Add a §Agent OS section to Macro `CLAUDE.md` **and** `AGENTS.md` — both, per the standing
   rule that durable operating rules live in both files (account-local memory does not reach
   Codex).
2. Same in Mastermind `AGENTS.md`/`CLAUDE.md`, and Terminal `terminal/AGENTS.md`.
3. Adopt the handoff protocol for every workstream-claimed session.
4. Backfill `DEC-*` for the **≤10 highest-value** decisions already made and currently
   load-bearing — for example the merge-on-green discipline, the model-routing tiers, the
   plain-copy asset pairing rule. **Backfill is capped deliberately:** an unbounded archaeology
   pass would consume a session and produce low-confidence reconstructions of reasoning nobody
   remembers. Ten high-confidence records beat a hundred guesses.

**Agent class.** Sonnet `Explore` for the backfill census (mechanical, non-code); main loop or
Opus `reviewer` to author the decision records (judgment).

**Validation.** ≥10 `DEC-*`, ≥5 `DSC-*`, ≥3 handoffs written by sessions *other than* the
Phase 0 session; `validate` green.

**What becomes possible.** Decision amnesia stops compounding. Codex workers can read what
Claude sessions learned.

## Phase 2 — Status generator and CEO brief  *(IMPLEMENTED)*

**Objective.** One generated page answers "what is happening". Closes **G5**.

**Dependencies.** Phase 0. (Independent of Phase 1 — it degrades gracefully on a thin record set.)

**Work.**
1. `scripts/agentos.py status` — join workstreams × `active_builds.v1` × `git worktree list`;
   emit `data/governance/agent_os_state.json` (`agent_os_state.v1`) + `docs/AGENT_OS_STATE.md`.
2. `scripts/agentos.py brief` — the CEO view; spec in `MASTERMIND_CEO_BRIEF_SPEC.md`.
3. Wire into the nightly beside `build_active_build_map.py`. **Fail-open, exit 0 always** — the
   nightly must never red because of this script, and there is direct precedent: ABM's own
   docstring commits to exactly this.
4. `--since` for the "what changed" view, computed from record `updated` + git history.

**Agent class.** Opus `builder`.

**Validation — all in `tests/test_agentos_status.py`, all green:**
- Pure function, PARTITIONED: whole-file byte identity with `--now` pinned, plus records-section
  identity with the wall clock live. The envelope (`generated_at`, `inputs.worktrees`,
  `inputs.active_builds_age_hours`, `inputs.degraded`) is excluded — a byte-identity test that
  needed a frozen clock to pass at all would hide nondeterminism inside the records.
- Fail-open proof, four ways: absent `active_builds.json`, absent sibling repo, unwritable
  output (previous artifact byte-unchanged), absent store → exit 0 with `degraded` populated.
- Fail-closed proof: a malformed record reds `validate` (exit 1) while `status` still reports
  the remaining records and names the excluded one in `degraded`.
- Zero network, proven twice: statically (no network module reaches `sys.modules`; no `gh`
  token in the source) and at runtime (`status` completes with `socket` disabled).
- I1: `status` and `brief` exit 0 on every input the suite can construct, including a store
  containing a file that is not even frontmatter.

**One regenerator.** The nightly, and only the nightly (`daily.yml`, immediately after
`build_active_build_map.py`, which is its PR-state input). No drift guard — see
`DEC:AGENTOS-NIGHTLY-IS-THE-ONLY-REGENERATOR` for why a per-PR guard would reintroduce the
shared-write conflict I2 exists to prevent.

**What becomes possible.** The CEO stops reconstructing state by hand. `needs_ceo` becomes a
filter instead of a reading exercise.

## Phase 3 — Context compiler

**Objective.** `compile-context --workstream X` returns a bounded, cited bundle. Closes **G6**.

**Dependencies.** Phase 0. Stronger with Phase 1's records.

**Work.**
1. Add `agentos/**` as a corpus to `config/context_index.yml` so existing retrieval covers it.
2. Implement `compile-context`: resolve workstream (directly, or via
   `context_index_query.py search` for free-text tasks), walk the link graph, apply exclusions
   (superseded, stale, other-program), enforce the token budget, emit the omission list.
3. Output `context_bundle.v1` — JSON plus a `--text` readable form, mirroring the existing
   `context_packet.v1` conventions rather than inventing new ones.

**Agent class.** Opus `builder`.

**Validation.** On the 6 seeded workstreams: bundle ≤ budget; every line cited; a superseded
decision and a stale discovery each provably excluded (assert on a fixture containing both —
an exclusion rule with no negative fixture is untested); omission list non-empty when the cap
binds.

**Explicit non-goal.** No embeddings, no vector store. Revisit only against a measured
miss-rate on the existing harness at `research/context_index/BENCHMARK_RESULTS.md`.

## Phase 4 — Hook auto-capture

**Objective.** Drive steady-state friction toward zero. The brief's principle 3, made real.

**Dependencies.** Phases 0 and 2, plus Phase 1 adoption evidence — **do not automate a format
that has not yet proven itself in manual use.**

**Work.**
1. Extend `.claude/hooks/ship_loop_guard.py` (report-only): if the branch matches a workstream's
   `claim.by` or `owns_paths`, auto-update `updated`, wave `status`, and `prs` on PR creation.
2. Stop-hook **reminder** — never a block — when a claimed workstream ends with no handoff.
3. `agentos claim` / `agentos release` helpers wrapping the advisory claim.

**Agent class.** Opus `builder`. Hook changes are high blast radius: they run on every session
in the fleet.

**Validation.** Hook changes ship report-only per census §6.6 (no auto-arming). Prove the hook
cannot block: a test asserting exit 0 on every Agent-OS-related condition, including malformed
records and a missing `agentos/` directory entirely.

**Risk, stated.** `ship_loop_guard.py` is ~2,465 LOC and gates every session in the fleet. A
defect here blocks the whole org. Mitigation: report-only, an explicit no-block test, and a
separate PR from any other change so it can be reverted alone.

## §2 What is deliberately NOT in the plan

Restated so no future session re-proposes them (architecture §13):

1. No task registry — waves inside workstreams. Conflict **C1**, Chairman's call.
2. No session tracking service — advisory claim only. Conflict **C2**, Chairman's call.
3. No scheduler, queue, bus, or daemon — census §6.4.
4. No vector database — §Phase 3 non-goal.
5. No unified store absorbing DNR, `governance.jsonl`, or masterplans — census §5.4.
6. No auto-arming authority — census §6.6.
7. No migration of the 137 masterplans — records **point at** prose, never absorb it.

## §3 Rollback

Every phase is independently revertible, which is a property of the storage choice rather than
a procedure bolted on:

| Phase | Rollback | Blast radius |
|---|---|---|
| 0 | `git revert` the PR | Zero — nothing reads `agentos/` yet |
| 1 | Records are inert data; stop writing them | Zero |
| 2 | Remove the nightly step | Zero — generated artifacts are derived |
| 3 | Remove the subcommand | Zero — the underlying index is unchanged |
| 4 | Revert the hook change alone | **Non-zero** — hooks gate every session; ship separately |

Only Phase 4 carries real risk, and it is the last phase, report-only, and isolated to its own PR.
