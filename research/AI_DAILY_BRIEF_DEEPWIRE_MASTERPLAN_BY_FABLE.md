## 0. In plain English

The AI Daily Brief (site/aibrief.html — three LLM-written morning briefs: Macro, China & HK, Bitcoin) is well-built but **blind to the Neural Web**: `engine/master_brain.py` hand-gathers regime/bonds/FX/BTC state while 44.5k lines of Neural Web organs — the world-state blackboard, contradiction detector, confluence engine, evidence clocks, theme theses, liquidity plumbing, causal lab, reliability kernel — sit next to it unread. It is also blind to the future: the repo has a full deterministic forward stack (macro-event calendar, CPI/NFP nowcasts with quantile bands, quarter-end/rebalance calendar, cycle-phase hazard model, historical base-rate screener) and none of it reaches the brief.

ADB wires both in, and wires Cortex both ways: the brief reads Cortex's committed deliberation memo when one lands (honestly disclosing when it didn't), and Cortex gains read-tools over the brief's own graded thesis ledger so it can audit the brief. Every new input is deterministic, display-tier, budgeted, and fail-open; the LLM's job stays what house law says it must be — synthesis and de-escalation over the trader's own deterministic outputs, never origination. "Superintelligent" here means: the brief finally sees everything the system knows (amassed context), says what's coming on the calendar with calibrated numbers where they exist, discloses what it doesn't know, and keeps a public graded track record of its own calls.

## 2. Rulings (ADB-R1..R16)

**ADB-R1 — Charter & never-block.** ADB implements W7's context intake for master_brain (N7 charter above). The W7b agentic runtime, model pinning, and Ask-the-Brain (W8b) are out of scope and not re-proposed. Every ADB input is fail-open: a missing/stale/degraded NW artifact, memo, or forward feed can never fail, delay, or gate the brief or the deploy. Cortex stays in its own downstream job; master_brain consumes **committed prior-run** artifacts only (the established `previous_run` pattern; verified ordering: master_brain daily.yml:891 runs before the NW builders in the same job, so it reads yesterday's committed NW state — correct by design).

**ADB-R2 — One budgeted composer.** All NW context enters the brief through one new module, `engine/neuralweb/brief_context.py`: `macro_slice()` (serialized ≤10KB) and `china_slice()` (≤6KB). Every block carries `as_of`, `display_only: true`, `_tape_family`, `_lead_lag`, and a `stale` flag (vs its synapse SLA, **keyed off the artifact's data `asof`, not `produced_at`** — the confluence_strength case: produced_at fresh, asof 2026-07-02). The composer's output must pass `_law.assert_no_authority()` in a unit test **that asserts on the serialized byte size**; Article-2 keys and authority booleans are structurally excluded; the 250-ticker `candidate_context` and any per-ticker lists are excluded by construction. Source artifacts are large (world_state 148KB, mastermind_context 236KB) — the composer subsets aggressively; it never passes an artifact through.

**ADB-R3 — Anti-double-count.** NW aggregations derived from the US price tape (breadth composites, market_plane verdict, price-derived contradictions) enter under `_tape_family: "nw_synthesis"` with an explicit `tape_note` stating they are cross-stock **aggregations of the same price tape** the macro block already reads — decomposition, not independent confirmation. Only rates/policy/flows-family NW blocks (liquidity_plumbing, rates_transmission, fx_dollar via world_state) may claim a different tape family. The macro system prompt gains a matching rule (extends the existing gather_state discipline, master_brain.py:826 docstring).

**ADB-R4 — Forward determinism (the predictive law).** The brief gains a deterministic `forward_calendar` state block, a **structured `forward_watch` output array** (each row: `{date, label, kind, numbers_verbatim}` — dates/bands/base rates as discrete rows the JS renders as a scannable list), and an optional short `forward_read` narrative string. Every forward-looking **number** must exist verbatim in `forward_calendar`; the LLM may narrate, contextualize, and de-escalate — it may never originate a probability, **perform arithmetic on or combine quoted base rates/hazards into any composite or joint read** (each row cites exactly one source artifact), or emit numeric confidence (CHF-R14/RF-16). Model-emitted fields inside release_forecast (`confidence`, `confidence_v2`) are quoted-not-originated and stay off the glance tier. Feeds: event_calendar high-impact strip (14d; bounded network IO acknowledged per R10), release_forecast top-3 upcoming (bands + market-implied + reaction playbook, disclosure fields verified against the live artifact, "no accuracy record yet" while n_graded=0, **Claims = benchmark line only** per the kill), rebalance_calendar.tag() quarter-end/recon distances, cycle_pattern hazards **only where hazard_src=MODEL and the gate for that entity's hazard direction × horizon = PASS** (gate_status is per-direction {up,down} × per-horizon — the direction whose hazard is being quoted is the gate consulted), odds_lab current-fingerprint base rate (n + Wilson bounds quoted), machine_registry hypothesis come-back dates (as "verdict due", never as evidence). Administration-timing / policy-intent predictions remain FORBIDDEN (PS-R1/PS-R4) — policy items are conditions-framed calendar entries, never "will fire" claims.

**ADB-R5 — Cortex → brief.** `gather_state()`/`gather_china_state()` read the last **committed** `data/neuralweb/cortex/memo.json`. If `run_status.status != "degraded"`: inject `{summary, what_fired, deserves_operator, decaying_families, memo_as_of, age_hours}`. If degraded (the steady state): inject only `{status: "degraded", reason}` — one honest line, no synthetic content. Memo age is always in-state so the LLM can weigh staleness. The reply-cache hash covers the whole serialized state (verified: `_mb_prompt_hash(model, system, user)` at :1154 with state json.dumps'd into `user` at :1291), so memo changes correctly bust the cache with zero cache-code change — asserted in a test.

**ADB-R6 — Brief → Cortex.** Cortex gains two read tools: `read_master_brain_theses` (last ≤20 rows of data/master_brain/theses.jsonl + track_record.json summary) and `read_master_brain_brief` (site/master_brief.json + china/btc, content fields only). The existing whitelist test covers only a hardcoded 6-tool subset — **W3 builds the full 3-way parity test** (every `_READ_TOOLS` name has a schema and dispatches; every schema name is whitelisted). System-prompt deliberation guide adds: review the brief's open theses against current contradictions; disagreements belong in `deserves_operator`. **Stated loop, adjudicated benign:** brief theses → cortex memo → brief cortex context is a display-tier narrative loop; it never touches a graded path (evaluate_cortex_hypotheses' self-ledger exclusions cover grading; attention grading reads firings, not memo prose; theses are graded by master_brain_scorer against realized prices only). A test asserts the memo-derived state block carries `is_context_only=true` and no thesis-staking logic reads it. **No new write tools; the 3/week hypothesis budget (QS-U2) and A2 earn-in mechanics are untouched.**
