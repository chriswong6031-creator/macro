## §0 The fast-track evidence doctrine (answers the operator's pacing demand)

Nothing in this program waits a year. The "12-month study" (#4506) was a
BACKTEST over twelve months of committed history — it ran in seven seconds.
The only genuinely calendar-gated object is forward maturation, and the
program's standing answer to it is now doctrine:

1. **Retro stand-in first.** Every candidate wiring is tested against the
   frozen 407-episode V1 frame (PIT joins, production scorer) the day it is
   proposed — the pattern that produced §2.10, the flow battery, and the v3
   era-retro. A stand-in verdict exists in hours, not quarters.
2. **Out-of-era corroboration second** where history permits (the #4506
   pattern: 12 months, thousands of events, half-split robustness).
3. **Forward races confirm, never block.** Ratified changes go LIVE with the
   displaced definition grading in parallel and named tripwires (G0.8);
   the forward ledger's job is to catch a wrong ratification fast, not to
   delay a right one. First tripwire reads land at ~60 matured episodes
   (~3–4 weeks at current admission rates), and the W0 artifact prints the
   race nightly from day one — partial reads visible immediately.
4. **Coverage debts are named, not waited on.** Where a store lacks PIT depth
   (THS membership history, own-market regime), the collector starts accruing
   NOW (W-C) and the analysis states its lookahead caveat instead of stalling.

## §2 The architecture: sensory cortex → bounded authorities → learning loop

### P-SI-2 — The CN Context Vector (sensory cortex; display/ledger tier, ships freely)

One nightly per-name context block, assembled where the candidates already
flow (`build_china_library`) and stamped onto `china_prophet_shadow`
candidates.parquet so every future study joins it PIT:

```
context = {
  theme:   {membership, level, timing_state, basket_phase, relay_count_3d},
  flow:    {lhb_3d, northbound_z20, margin_d20, holder_trend, block_10d,
            buyback_active, turnover_pctile}   # axes that pass the battery
  policy:  {backed_flag, last_event_days}       # from policy_watch tags
  regime:  {own_market_quad, global_beta_state, qvix_regime}
  risk:    {chase_composite, limit_band, risk_line_-10pct}
}
```

Zero authority at birth. Its value is that the ENTIRE dashboard's knowledge
becomes joinable evidence the night it ships — the difference between "we have
the data somewhere" and "every episode carries its context forever."

### P-SI-3 — The bounded-authority ladder (one axis per adjudication, glass-box law)

Each context axis that shows separation follows EXACTLY the theme_timing
precedent: retro stand-in → out-of-era corroboration where possible →
operator-ratified bounded authority (a capped score component or a featured
prior, never a hidden blend) → displaced-definition shadow + named tripwire.
**No composite black box, ever**: the score stays a sum of individually
defensible, individually revertible legs. Current queue, in evidence order:

1. Flow axes — pending the battery's ranked verdicts (LHB desk quality first:
   it directly targets the relay bimodality — who bought the limit day).
2. Policy backing — retro test on the episode frame next (did policy-backed
   themes' picks outperform policy-vacuum themes'?), then a context chip, then
   the ladder.
3. Crowding/turnover percentile — the cheap always-available axis.

### P-SI-4 — Regime-conditional composition (the US lesson, pre-empted)

The US audit proved one entry family cannot serve two regimes. CN's washout
family thrives BECAUSE the tape mean-reverts — when CN turns trending (it
does, violently), today's Prophet would repeat the US failure in mirror image.
The continuation-watch ledger (W-C) is the counter-family accruing NOW; the
promotion trigger is regime-conditional: when `own_market_regime` shows a
sustained trending quad AND the continuation ledger's matured record clears
its prereg, the door opens with regime-scoped weight. Until the regime store
carries a second regime, this stays chartered, not built — the honest
data-gate, stated.

### P-SI-5 — Neural Web integration (both directions, lawful)

- **Prophet → NW:** every CN Prophet artifact registers as a synapse with its
  honest grade (W0 telemetry = ops-telemetry; track ledgers = graded records;
  v3 lanes = display+scored-definition). The miss-audit and tripwire states
  become first-class synapses so the brain can answer "why isn't X featured
  tonight" from artifacts, never from vibes.
- **NW → Prophet:** graded cross-lobe context (global-beta stress, liquidity
  regime, USD/CNH) enters ONLY through the P-SI-3 ladder like any other axis —
  the constitution's A7 ban stands: the LLM/brain never originates or escalates
  a signal; it narrates and de-escalates calibrated keys only.
- **Chat visibility:** the Live Market State Packet carries the CN board block
  (W-C), so the Mastermind chat explains picks, absences, demotions, and the
  v3-vs-v2 race in plain words on both languages.

### P-SI-6 — Cadence, honestly assessed

A-share ignition is intraday (seals by mid-morning), and the US has
prophet_live for intraday re-probes. CN's collectors are end-of-day, and
crucially **T+1 execution blunts the urgency**: a signal detected at the close
fills at the next open exactly as a midday detection would — the fill is the
same bar. The measured cost of EOD-only detection is therefore small for the
incumbent family; where it binds is relay-EARLY detection (being first into a
theme's second day). Verdict: intraday CN quotes are a data-acquisition
decision for the operator (cost vs the relay-early margin), NOT a silent gap —
chartered as an open question with the T+1 analysis attached, no build until
the data exists.

### P-SI-7 — The learning loop closes itself

W0 already grades nightly. The remaining half (W6): the postmortem taxonomy
auto-stamps every matured loser (chase / relay-late / theme-fade /
sector-cohort / churn / other) and every missed runner (funnel stage), and a
weekly governor emits a delta report whose findings arrive as DRAFT preregs —
machine-drafted, operator-adjudicated, never hot-patched. The system proposes
its own next experiments; authority still moves only by ratification.
