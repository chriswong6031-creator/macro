# Ownership, sequence and authority consequence

The W0 records release creates organizational and scientific boundaries only. It performs no
market-data collection, backfill, indicator calculation, signal mutation, outcome read, runtime
admission, worker START, Slack delivery, Linear projection, product change or production proof.

The first empirical child, W1A, may return only `ARTIFACT`, `UNRESOLVED_DATA` or
`MECHANICALLY_SURVIVES`. It must set final usefulness-mechanism classification to null. A separate
W1B preregistration and explicit Sol continuation are required before `FILTER_MEMORY`,
`SESSION_GRAMMAR` or `MIXED` may be concluded from localization/risk evidence.
`STRUCTURE_SCALE`, `INFORMATION_TIME` and `REGIME_MULTISCALE` require still later separately
preregistered waves. A null or kill is an acceptable completion.
