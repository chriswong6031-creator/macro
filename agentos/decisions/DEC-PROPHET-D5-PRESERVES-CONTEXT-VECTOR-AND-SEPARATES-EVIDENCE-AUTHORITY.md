## Consequence

The first D5 implementation is not a Context Vector migration and cannot precede the canonical B1 episode. It starts prospectively from an owner-issued canonical V4 candidate episode, reads one mature specialist owner through an allowlisted adapter, and feeds one read-only consumer. Existing Context Vector history remains available by exact reference.

An unbuilt adapter produces no evidence-family object. Once an adapter exists, genuine per-episode missingness uses the contract's orthogonal applicability/coverage/freshness/rights/identity axes and typed observation absence reasons.

D5 does not rank. Later deterministic E1 may consume only decision-admissible owner-native observations explicitly bound to accepted Conditional Fusion members/versions under the Fusion/E1 owner law.

## Reopening condition

Reopen only if a real B1 episode implementation or source-owner contract proves that referencing the Context Vector cannot preserve a required PIT capability, or if the Conditional Fusion owner changes its taxonomy/authority contract. Serialization preference alone is not a reopening condition.
