## Consequence

The first D5 implementation is not a Context Vector migration. It starts
prospectively from canonical candidate episodes, reads one mature specialist owner
through an allowlisted adapter, and feeds one read-only consumer. Existing Context
Vector history remains available by exact reference.

## Reopening condition

Reopen only if a real B1 episode implementation or source-owner contract proves that
referencing the Context Vector cannot preserve a required PIT capability, or if the
Conditional Fusion owner changes its taxonomy/authority contract. Serialization
preference alone is not a reopening condition.
