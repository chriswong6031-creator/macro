# Decision consequences

## What is frozen

- One durable baseline plus one allowlisted live projection; not two canonical states.
- Terminal Quote Plane is the current quote owner.
- Macro API is the public projection boundary.
- One controller owns each live DOM value.
- R1A changes observation only.
- R1B streaming and all intelligence recomputation are separate.
- Failure resolves to delayed/partial/stale/unavailable/baked, never false-current.

## What this record does not do

This decision is architecture/organizational truth only. It creates no endpoint, branch execution,
worker, queue, scheduler, stream, database, credential, deployment or production capability. The
R1A implementation remains `NOT_BUILT` until a separately commissioned worker returns reviewed code
and production proof.
