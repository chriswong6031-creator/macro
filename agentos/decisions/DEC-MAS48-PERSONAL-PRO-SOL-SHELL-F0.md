supersedes only earlier MAS-48 product/sequencing assumptions that conflict with #99:

1. Executive MCP is mandatory for the Personal-Pro CEO journey;
2. post-PR-A work is one monolithic PR-B then PR-C;
3. the CEO shell requires ChatGPT Business/private Plugin infrastructure.

* Executive SQLite/Runtime is the sole Job/Attempt/Worker/Event lifecycle authority;

* PR-A remains the merged two-schema submit/status hermetic capability;

* Agent OS is organizational memory, not an execution/task store;

* no Slack lifecycle/dedupe/replay-cursor/message-ts database, direct SQLite or broad Operator access is authorized;
* Wake and generic autonomous `#agent-dispatch` execution remain outside MAS-48 proof.
