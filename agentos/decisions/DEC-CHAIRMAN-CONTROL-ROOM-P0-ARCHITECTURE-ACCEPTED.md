## Operational consequence

The accepted P0 is an independently useful local product, not a prerequisite-shaped
architecture exercise. It must show real current organizational work and open real
Sol/Fable/worker/evidence surfaces on Chris's M3 Ultra.

The local `mastermind.surface_bindings.v1` file is navigation preference only. It
may never contain or author lifecycle status, priority, next action, completion,
attention target, authority, lease, result, prompt text, credentials or provider
tokens.

## Held after P0

Automatic return routing, prompt submission, CEO wake, generic Slack dispatch,
tmux-owned lifecycle and multi-host load balancing remain separate later programs.
