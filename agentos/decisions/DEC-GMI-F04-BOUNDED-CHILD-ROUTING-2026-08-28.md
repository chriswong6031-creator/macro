# Binding routing correction

The F04 parent remains active and logically owned by the existing COO/F04 responsibility. Provider
sessions are execution resources, not organizational identities. A Fable provider conversation is
therefore not required merely to start a child whose architecture and acceptance boundary are already
fully frozen.

## D2C / D2D release rule

After this routing correction is main-canonical, Sol may commission D2C and D2D as separate bounded
children when a fresh current-state/path census is clear. Each commission uses the current manual
handoff contract:

- `RECEIVER_BINDING_MODE: CAPACITY_SELECTABLE`;
- `PREFERRED_AVENUE: Terra` unless fresh mission evidence justifies escalation;
- one stable existing operation key and one carrier;
- separate ACK, WATCH_ARMED and START;
- no self-claim from an avenue label;
- post-START binding remains sticky;
- terminal child STOP authorizes no successor.

D2C and D2D may run concurrently only after the receiving workers' exact modifying-path censuses prove
disjointness. If their actual planned changes collide, sequence them rather than creating a second
owner or force-merging.

## Fable escalation rule

Escalate a child to Fable only when current evidence establishes a principal-level condition such as:

- unresolved cross-owner architecture/authority collision;
- inability to freeze a safe source/identity/rights boundary;
- sustained multi-repository integration ambiguity that bounded workers cannot resolve;
- stalled-program recovery after effect/state reconciliation.

Routine implementation, tests, CI repair, current-source archaeology and bounded independent review
remain worker labor and should not consume Fable by default.

## Unchanged architecture

This ruling changes no GMI graph identity, event/source/identity owner, ThemeState authority, K3-D
boundary, TXI/incorporation/dislocation ownership, Prophet/Entry authority or MarketOntology parity
scope. The finish-and-fold sequence remains:

`D2C + D2D -> D2E -> W3B -> W3C -> GMI development close`

No standalone GMI W4/W5/W6 is restored.
