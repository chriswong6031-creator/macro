# Binding no-rebuild and authority freeze

1. `market_memory.as_known_at.v1` is the one decision-time context contract. New semantics require an explicit version, not a sibling context plane.
2. `market_memory_pit`, trusted memory, production-record stores and domain-owned source stores are the canonical memory substrate family. Do not create a second Market Memory DB/vector/history store.
3. Market Memory composes and references domain-owned evidence; it does not rewrite source, identity, calendar, outcome, options or Prophet history.
4. Missing contemporaneous state stays missing. Reconstruction is typed weaker evidence and cannot satisfy operational-PIT proof.
5. Corrections/versioning append lineage. Earlier known-at bytes and semantics never mutate in place.
6. `brain_analogues` and `event_atlas` remain existing macro/symbol analogue engines. Production W4B retrieval may add a pinned PIT population reader; it must not duplicate those engines.
7. Existing Market Memory playback/replay surfaces are the simulator/replay family. No second simulator.
8. W4A retrieval and W5A Cortex modules own conformance/guard semantics but are not production claims. W4B/W5B must add real readers while preserving their leakage/authority laws.
9. Research Factory owns research candidate/experiment lifecycle. Market Memory gets adapters/consumers, not a new research lifecycle.
10. Operating Cortex is read-only/contextual with no hidden Market Memory writer/store/rank/gate/size/trade authority.
11. Executive OS owns runtime Job/Attempt/Worker/Event state; Agent OS owns durable organizational workstream/decision/discovery/handoff state. Slack and Linear do not become lifecycle truth.
12. Every modifying child wave uses one carrier, a fresh owner/path/open-PR collision census, and one independently useful production/research capability per PR.

# Completion law

Market Memory stays open until a real production path proves exact known-at capture,
append-only corrections, honest pinned-population retrieval without hindsight leakage,
authorized cognitive/research consumer use, operator-visible provenance/failure states and
learning instrumentation — or a component is explicitly rejected by evidence/architecture.
