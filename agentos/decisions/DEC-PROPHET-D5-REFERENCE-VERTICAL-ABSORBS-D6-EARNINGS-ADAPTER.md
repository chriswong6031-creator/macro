## Narrow ruling

This decision changes sequencing and durable interpretation only. It does not modify
runtime code, broaden Earnings coverage, mark D5 production-proven, start another
family adapter, authorize D7, or advance any ranking, entry, sizing, portfolio or trade
authority.

The old D6 wave should be represented as `dropped` with an explicit absorbed-by-D5
receipt. `Dropped` here means **no separate implementation is owed**; it does not mean
the Earnings capability failed or was rejected. The capability exists inside D5 and
still owes the authenticated production proof recorded by issue #6797.

## Future Earnings work

Future work may still be valuable, including broader issuer/event coverage, expectation
state, trajectory, surprise/materiality, correction observability and user-facing
composition. Those are new capability questions. They require a fresh operation key,
current EIOS owner boundary, exact data/rights clocks, one independently useful journey
and separate production proof. None is authorized by this recut.
