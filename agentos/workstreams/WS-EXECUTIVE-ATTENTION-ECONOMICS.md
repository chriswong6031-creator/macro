## Current architecture ruling

The accepted mechanism is a closed **Executive Attention Frontier**, not a score or inbox:

`canonical facts -> authority partition -> cognition admission -> disposition -> exact bundle -> Pareto frontier -> deterministic local service -> read-only projections`.

Frozen attention dispositions are `INTERRUPT_NOW`, `FOCUS_NOW`, `BATCH_NEXT`,
`AUTONOMOUS_CONTINUE`, `VALID_WAIT`, `RECONCILE_FIRST`, `COVERED_BY_BUNDLE`, and
`NON_ACTIONABLE`. They are never lifecycle states.

Within an authority partition, actionable demand is compared using source-backed time pressure,
actual impact, reversibility, dependency-unblock leverage, active resource burn, autonomy remaining,
information/wait option, evidence quality, ready age and context affinity. Unknown optional factors
remain unknown; load-bearing uncertainty may force `RECONCILE_FIRST`.

The compact frontier always exposes true interrupts. Non-emergency batching uses exact context/root
relations plus a source-backed oldest-ready fairness sentinel. That sentinel never suppresses an
emergency and an intentional valid wait does not accrue false aging before review is due.
