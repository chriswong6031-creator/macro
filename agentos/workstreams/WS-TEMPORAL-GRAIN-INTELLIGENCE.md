## Scientific prior

The current ruling is `MIXED — SESSION_GRAMMAR + FILTER_MEMORY, with UNRESOLVED_DATA on exact
motivating-chart reproduction`. It is a hypothesis ranking, not a validated signal claim.

The first independently useful capability is an exact chart-packet and mechanical artifact-attack
harness. It must establish that the observed WMT/silver construction is reproducible, identify
whether it survives G/A/K/D perturbations, or stop honestly at `ARTIFACT`/`UNRESOLVED_DATA`.
`MECHANICALLY_SURVIVES` licenses only a separately preregistered W1B usefulness test.

## Ownership boundary

- Market Ontology / current market-data and instrument-identity owners supply instrument, vendor,
  venue, contract, roll, session, timezone, adjustment, correction and rights identity.
- Signal Engine research owns the deterministic kernel signature and G/A/K/D harness.
- Stock Identity supplies existing structural measurements read-only.
- Entry Radar/session infrastructure supplies reusable session-aware precedent without losing
  tactical ownership.
- TrialLedger/Evaluation OS owns look budgets and later outcome evaluation.
- Agent OS owns this durable organizational workstream; GitHub owns implementation/evidence;
  Executive OS owns runtime lifecycle if a runtime operation is later admitted.

## Completion truth

A null, artifact or abstention is successful scientific completion when it closes the motivating
claim at the frozen bar. W1A mechanical survival is not usefulness proof. A positive W1B mechanism
result remains zero-authority and must pass the later outcome-blind derivation and untouched
confirmation waves before any product or signal proposal.
