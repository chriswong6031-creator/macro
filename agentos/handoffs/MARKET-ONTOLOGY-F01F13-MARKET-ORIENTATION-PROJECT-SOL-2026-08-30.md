## 7. Complete user journey

### Morning current state

1. User opens the existing AI Brief family before the U.S. session.
2. The page states market session date, observation cut, generated time, and source coverage.
3. User sees deterministic changes since prior close, today's calendar, and cross-asset disagreements.
4. Each block shows current/stale/unavailable state and links to the owning product.
5. An unfamiliar term opens `reference.html#<stable-slug>` or an equivalent accessible drawer/deep link.
6. The definition gives plain EN/ZH meaning, basis/unit, why it matters, caveats, owner/source, and related terms.
7. Back/close returns to the same morning section and preserves language/theme/scroll/focus.
8. The prior-close AI narrative is visible only as separately timestamped context.

### Degraded state

The user sees which minimum morning sources are unavailable or stale and may inspect last-known owner data.
The product never relabels stale EOD data as a fresh morning read.

### Reference-only state

A user can open the Reference surface directly, search by English/Chinese label or alias, filter by family,
follow stable anchors, inspect deprecation/replacement, and reach the owning product.
