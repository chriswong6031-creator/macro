## Observable mission

Let a user understand how a canonical event/scenario/security context intersects the actual Portfolio, conventional risk, concentration/factors/liquidity and research construction choices; then monitor material changes with reliable receipts. Every book aggregate visibly states the population/basis/coverage it actually used.

## Scope / journey

Canonical owner-scoped holdings + Stock Identity → risk/factor/correlation/liquidity owners → event/K5/scenario refs → direct/second-order affected positions with deduplicated touched weight → conventional risk/portfolio context → research Portfolio Constructor/proposal (non-execution) → alerts/monitor settings → durable attempt/success/error/output/coverage receipts. Watchlists remain attention truth, not holdings.

## Data/null/correction law

Each aggregate carries total/included/excluded denominator, live/fallback/missing basis, timestamps and reconciliation. Dominant material degradation propagates to panel state. Missing price/identity/risk input is not zero. Holdings updates remain stable-ID/version/idempotent canonical writes under existing owner law. Alert last-attempt and last-success are distinct; failed/partial run cannot render calm/current.

## Method / failure law

Risk metrics reuse canonical formula/model owners with definition, benchmark, horizon, annualization and version. Statistical scenarios/factors retain native uncertainty. Portfolio Constructor is research proposal only; model/LLM can explain but cannot silently rebalance or size. Fail/degrade on incomplete denominator, mixed basis, stale quotes, identity conflict, benchmark/model mismatch, insufficient history, unavailable liquidity source, write ambiguity, alert execution failure or private-context boundary.
