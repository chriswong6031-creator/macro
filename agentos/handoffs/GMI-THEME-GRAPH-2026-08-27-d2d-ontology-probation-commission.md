## Observable mission

After D2D, Mastermind can navigate its broad market structure without semantic laundering: an exact security can retain multiple owner structural classifications and multiple local theme memberships; local/vendor concepts can carry explicit typed parent/equivalence/expression relationships where evidence supports them; canonical strategic mapping is curated and sparse when necessary; and every unresolved proposal remains visible rather than force-mapped.

The semantic plane is already much wider than the 18 strategic themes, but the user job requires a coherent hierarchy and graph neighborhood rather than hundreds of disconnected local labels. D2D turns the existing graph into a governed ontology while preserving the key moat: source provenance, local granularity, overlap and honest uncertainty.

## Complete user / machine journey

1. Start from an exact company/security, a structural sector/industry/subsector node/reference, a local theme, or a canonical theme.
2. Resolve the subject through existing identity/owner seams.
3. Return every PIT-valid local membership at the requested as-of date.
4. Return structural classification references only where the canonical owner supports them.
5. Traverse typed ontology relationships without conflating:
   - taxonomy parent/child;
   - source-local concept identity;
   - curated vocabulary equivalence/resolution;
   - basket/theme expression;
   - membership.
6. If a local concept has no justified canonical mapping, return it as an independent local concept with `canonical_mapping = null`/equivalent explicit state.
7. If a candidate mapping exists but is not adjudicated, surface probation state to authorized machine/research tooling; do not make it graph truth.
8. Preserve many-to-many overlap: one company and one local concept may participate in several valid neighborhoods.

## Data / contract / time / null / correction law

- Source-native local IDs are never replaced by human-readable labels.
- Canonical mapping is a separate relationship, not a rename/overwrite of the local node.
- `unmapped`, `probation`, `rejected` and `accepted` must remain distinguishable states in the appropriate existing curation plane.
- Adjudication records carry reviewer/authority basis and applicable clocks/version, using current probation law rather than a new approval database.
- A source rename does not mint a new concept identity unless the source identity actually changed; suspected rename stays reviewable.
- Structural-classification references inherit owner corrections and clocks.
- Mapping changes append/record new belief under existing graph law; historical belief is not silently rewritten.
- Rights tier travels with source/edge evidence and can limit public display even when internal mapping is valid.

## Deterministic / statistical / model-generated method

Candidate generation may use deterministic lexical/structural heuristics or a model only as a proposal aid if current probation law permits it. Final graph admission is never automatic from similarity, embedding, label equality or an LLM. Curated/adjudicated evidence controls truth. Models may summarize accepted mappings for display later but cannot originate authority here.
