## Observable mission

After W3B, every eligible local theme can accrue a correction-safe nightly state made of named, source-owned legs, and every eligible canonical theme can have a separate aggregate state without erasing local distinctions. Ineligible/sparse/stale/incoherent themes return a typed abstention. Neural Web and machine consumers read this one GMI-owned state authority rather than an independent predecessor composition.

## Why it matters

Theme membership alone cannot tell whether a semantic neighborhood is broadening, concentrating, emerging or fading. W3B is the measurement bridge from ontology to intelligence. It must be strong enough for explanation and later cohort learning while remaining explicitly non-ranking/non-trading.

## Complete user / machine journey

1. Caller requests state for local/canonical theme and as-of cutoff.
2. Resolve exact theme identity and PIT membership from GMI.
3. Run eligibility using preregistered/history-baked criteria: member breadth, identity integrity, PIT depth, price coverage, missingness, concentration/effective breadth, source freshness, survivorship/era and coherence.
4. If ineligible, return typed no-state/abstention with failing criteria and coverage denominator.
5. If eligible, read named owner measurements only; preserve each leg’s source/as-of/coverage/units/era/null state.
6. Compute only W3B-owned deterministic transformations explicitly frozen by contract; no owner-statistic duplication.
7. Emit local ThemeState. If a legitimate canonical mapping exists, compute canonical ThemeState separately from its lawful membership/child inputs; never replace local state.
8. Append state transitions/PIT history when tracked state changes; later corrections create later belief, not rewritten prior state.
9. Expose the same canonical state to Neural Web/machine consumers through one accepted reader/projection.

## Data / contract / time / null / correction law

- State key includes stable theme identity and effective/knowledge clocks sufficient for PIT replay.
- Eligibility and every leg carry denominator/coverage; null is typed, never neutral/zero.
- Reconstruction vs observed era is explicit in state and consequence records.
- Stale owner inputs degrade/abstain by contract rather than retaining a fresh-looking aggregate.
- Local and canonical states are distinct records/identities.
- A corrected membership or owner input changes only later beliefs; historical decision-time reads remain reproducible.
- Consequence transition accrual reuses canonical grading/qledger/placebo infrastructure; W3B does not create a grader.
