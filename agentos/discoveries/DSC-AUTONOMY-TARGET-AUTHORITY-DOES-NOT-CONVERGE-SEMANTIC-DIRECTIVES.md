# Evidence boundary

This discovery does not say current target resolution is broken. Stage A and Stage B remain the
correct owners of **who may act**. It records a different missing contract: **which semantic decision
became effective** for one exact return.

The distinction became load-bearing when live autonomy carriers contained contradictory action-looking
instructions. Human procedure and later Chairman messages repaired precedence, but the Runtime could
not itself reject the stale semantic instruction before it reached the worker because no directive
revision/compare-and-swap Event existed.

# Required response

Use the existing Runtime Event plane for one content-bound directive family and the existing COO
cycle for one downstream consumer. Preserve W3C, Wake, Agent Relay and Slack as attention/transport.
Do not create a directive database, Slack command bus, second lifecycle, target registry, watcher
registry or retry service.
