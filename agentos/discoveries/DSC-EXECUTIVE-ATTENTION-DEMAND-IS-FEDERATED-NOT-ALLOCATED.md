## Observed owner split

- Agent OS owns durable responsibilities, authored decisions, dependencies, waits and `needs_ceo`.
- Executive OS owns Job/Attempt/Worker/Event lifecycle and effect state.
- RuntimeBinding/session owners own exact reasoning/execution surfaces.
- Wake/Executive Inbox own attention-obligation identity/delivery source semantics.
- Capacity/Model Router own placement/eligibility, not executive priority.
- OCR-6 Steward composes those sources read-only and is currently being correctness-repaired.
- Control Room composes operating views and explicitly must not become another truth store.

These are complementary. None should be widened into a second company scheduler merely to solve
attention economics.

## Scale implication

The company already runs many legitimate independent workstreams and stewardship loops. As coverage
improves, the number of *valid* attention signals will rise even if every local detector is correct.
Therefore reducing false positives at each detector is necessary but insufficient. The organization
needs a portfolio cognition-allocation view that can say "not now, because safe progress continues",
"wait intentionally until this evidence boundary", "one root decision covers these twenty symptoms",
and "this old item must remain visible even though newer work keeps arriving".

## Design consequence

The gap is an **allocation transform**, not a missing queue:

```text
valid demand + organizational/runtime context
-> authority-preserving cognition disposition
-> exact fan-in / partial-order frontier
-> compact read projection
```

This discovery is intentionally separate from the final F0 architecture decision so a future
canonical owner can falsify the premise without rewriting the historical reasoning record.
