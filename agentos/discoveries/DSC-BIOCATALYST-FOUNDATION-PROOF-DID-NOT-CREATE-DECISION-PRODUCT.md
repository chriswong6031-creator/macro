## Anti-regression question

Before accepting any future BioCatalyst PR or wave, answer:

> What user or machine capability now exists that did not before, and can a
> real entitled user complete the corresponding discovery/investigation task
> on the production path?

If the answer is only a schema, source, store, validator, library, model class,
CI guard, architecture document or truthful unavailable state, the work may be
necessary foundation but it is not the Decision Intelligence product milestone
unless the accepted wave explicitly says it is deliberately inert and names the
next real consumer.
