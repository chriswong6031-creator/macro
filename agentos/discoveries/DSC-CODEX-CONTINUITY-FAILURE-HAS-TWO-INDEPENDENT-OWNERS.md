sent bounded direct assignments, current receiver rulings and repeated attention
edges. Several exact Codex tasks remained delivery-only until the Chairman
foregrounded the native task. Once foregrounded, ORION immediately recovered the
canonical carrier, removed the terminal predecessor source and followed the
existing ACK -> watcher -> START sequence. That is evidence that dormant native

treating that narrow watcher prompt as a scope rule after a valid later carrier

heartbeat serving permanent seat/principal/sibling sources could be paused when
one child stopped, suppressing unrelated future attention.
