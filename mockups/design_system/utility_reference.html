Archetype I, the 404 case. One card on the canvas — nesting depth 1, no aurora, no ambient field, no second surface. Exactly one way forward: a single action, no menu, no search box, no “popular pages” list. The link farm is the anti-pattern this page exists to refuse, and it is what site/start.html is today (142 links, a page-local wordmark, repeated mega-nav blocks) — the Today reference replaces that page; this one must never become it.

I 型页面的 404 情形。画布上只有一张卡片——嵌套深度 1，无极光背景、无氛围层、无第二表面。只给一条出路：单一动作，不放菜单、不放搜索框、不放「热门页面」列表。链接农场正是本页要拒绝的反面样式，而现行 site/start.html 恰恰就是它（142 条链接、页面级自有字标、重复的巨型导航块）——今日参考稿替换那个页面，本页则永远不该变成它。

The status code is set in mono because an HTTP status is a FIGURE (§4: mono for figures, never for words) — it is the only mono on the page, and the only structural device: a hairline under it files the card as a record rather than decorating it. Motion is a status channel (§7); nothing here is live or ongoing, so the action keeps the primary CTA surface but not its pulse. The brand stays quiet: a wordmark, not a header family. Zero ambient: the site aurora is suppressed on this family alone, so the card is the only thing on the canvas. Same organization as today_reference.html, deliberately emptier.

状态码用等宽字体，因为 HTTP 状态是一个数字（§4：等宽只给数字，绝不给词语）——它是全页唯一的等宽元素，也是唯一的结构装置：其下一条细线把卡片归档为一条记录，而不是给它加装饰。动效是状态通道（§7）；此处没有任何实时或进行中的事，因此动作保留主行动按钮的样式而不保留其呼吸。品牌保持安静：只是一个字标，不是一整套页头。零氛围层：仅本页族关闭全站极光背景，画布上只剩这张卡片。与 today_reference.html 同源，但刻意更空。
