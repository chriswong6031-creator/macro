?Sorted by how many funds are buying the same name at once, then by how much conviction sits behind it. A name reaches the board only when at least two separately-managed funds have touched it. Breadth comes first on purpose: a count cannot be inflated by one large fund, one large position or one loud sponsor, which makes it the hardest number on this page to manipulate.先按有多少只基金同时买入同一个股排序，再看背后的信念规模。只有当至少两只独立管理的基金触及该个股时，它才会进入看板。广度优先是刻意的：数量无法被单只大基金、单个大仓位或某家高调发行商操纵，因此它是本页最难被扭曲的数字。 EssentialEssential

Fresh conviction全新建仓

?A brand-new position is the highest-information version of an add: a manager who did not own a name and now does has made a decision that cannot be explained by drift, rebalancing or index maintenance. Two or more funds opening the same name in the same window is the strongest cross-manager read on this page. One fund opening it is a lead, not a signal — and nothing here says the entry is timed.全新建仓是信息量最大的增持形式：此前不持有、现在持有，这个决定无法用漂移、再平衡或指数维护来解释。两只及以上基金在同一窗口内建立同一仓位，是本页最强的跨经理人解读。仅一只基金建仓属于线索而非信号——此处也不代表入场时机已到。

Positions opened from zero this cycle — the strongest single tell.本轮从零开立的仓位——最强的单一信号。

The tape behind it背后的行情

?Trailing ratio momentum across public ETF pairs — what the market has been rewarding lately. It is CONTEXT for the fund decisions above, not an input to them: no name is re-ranked because the backdrop is risk-on. Accumulation with the backdrop is easier to hold; accumulation against it needs a longer horizon and a smaller size.公开 ETF 配对的滚动比值动量——市场近期在奖励什么。它是上方基金决策的背景，而非其输入：不会因为环境偏risk-on而对任何个股重新排序。顺势增持更容易持有；逆势增持则需要更长的持有期与更小的仓位。

Buying with the tape confirms; buying against it needs patience.顺势买入是确认；逆势买入则需要耐心。
