🛑 Extension penalty拉伸惩罚 — subtract-only: the more a name has already run (20-day gain, distance above the 50/200-day averages), the lower it ranks — so the buy lane keeps an entry.只减不加：已经涨得越多（20日涨幅、高出50／200日均线），排名越低 — 让买入区始终留有入场点。
