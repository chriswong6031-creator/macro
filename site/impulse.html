📐 How the impulse score is built冲量分如何计算

⚡ Acceleration加速度 — fast (5d) return slope pulling above the slow (20d) slope, normalised by the name’s own volatility, plus a denoised MACD-histogram impulse.5日收益斜率上穿20日斜率，按个股自身波动归一，并叠加去噪的MACD柱状冲量。
📊 Volume confirmation成交量确认 — relative volume vs the 20-day median and a short/slow volume ratio — is participation waking up?相对成交量 vs 20日中位数，及短／长量比 — 参与度是否被唤醒？
🛑 Extension penalty拉伸惩罚 — subtract-only: the more a name has already run (20-day gain, distance above the 50/200-day averages), the lower it ranks — so the buy lane keeps an entry.只减不加：已经涨得越多（20日涨幅、高出50／200日均线），排名越低 — 让买入区始终留有入场点。
🧭 Absolute-trend gate绝对趋势闸 — names in an active down-trend are excluded from the buy lane — no falling knives.处于明确下行趋势的个股被排除在买入区外 — 不接飞刀。
